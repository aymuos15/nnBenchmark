# dataset preparation

**nnBenchmark uses nnU-Net format (Medical Segmentation Decathlon structure)**

## structure

```
datasets/Dataset001_Hippo/
├── dataset.json          # metadata
├── splits.json           # generated by nnBench.plan
├── imagesTr/            # {case_id}_{modality}.ext
├── labelsTr/            # {case_id}.ext
├── imagesTs/            # optional
└── labelsTs/            # optional
```

## dataset.json

```json
{
  "name": "Hippo",
  "description": "hippocampus segmentation",
  "labels": {
    "background": 0,
    "Anterior": 1,
    "Posterior": 2
  },
  "modality": {
    "0": "MRI"
  },
  "numTraining": 260,
  "file_ending": ".nii.gz"
}
```

## supported formats

- 3D: `.nii.gz`, `.nii`
- 2D: `.png`, `.jpg`, `.jpeg`
