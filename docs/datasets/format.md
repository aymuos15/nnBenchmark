# Dataset Format

nnBenchmark uses the [nnU-Net dataset format](https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/dataset_format.md).

## Basic Structure

```
datasets/Dataset{XXX}_{Name}/
├── dataset.json          # metadata (required)
├── splits.json           # train/val/test splits (generated by nnBench.plan)
├── imagesTr/             # training images
├── labelsTr/             # training labels
├── imagesTs/             # test images (optional)
└── labelsTs/             # test labels (optional)
```

## File Naming

- **Training images**: `{case_id}_{XXXX}.{ext}` (e.g., `case_001_0000.nii.gz`, `case_001_0001.nii.gz`)
  - Four-digit channel index (0000, 0001, etc.) identifies each channel
  - Multi-channel datasets have multiple files per case (e.g., T1, T2, FLAIR → 3 files)
  - Channel naming is defined in `channel_names` field in dataset.json
- **Training labels**: `{case_id}.{ext}` (e.g., `case_001.nii.gz`)
  - Single label file per case regardless of number of input channels

## Supported Formats

- **3D**: `.nii.gz`, `.nii`
- **2D**: `.png`, `.jpg`, `.jpeg`

For full specifications and advanced configurations, see the [nnU-Net dataset format documentation](https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/dataset_format.md).
